# kkrules

两份分流脚本：[Clash Verge Rev](./Clash-Verge-Rev-RouteKit-Premium-Primary-v4.js) · [Bettbox Android](./Bettbox-RouteKit-Premium-Primary-v1.js)。

先选精品机场订阅，再仅在本机填写脚本顶部的经济机场 Clash/Mihomo 订阅链接。Bettbox 版在脚本覆写入口使用；若要采用脚本的 DNS 设置，请关闭 App 的 DNS 覆写。

规则来自 [blackmatrix7](https://github.com/blackmatrix7/ios_rule_script) 和 [MetaCubeX](https://github.com/MetaCubeX/meta-rules-dat)；脚本参考 [Mihomo-RouteKit](https://github.com/skullvek/Mihomo-RouteKit/tree/760a342e91568167ee608a6fb4a6b721b65f5a76)。`rules/` 是 RouteKit 三份自定义规则的备份，当前脚本仍引用上游。
