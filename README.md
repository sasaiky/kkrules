# kkrules

个人维护的 Clash Verge Rev 扩展脚本：[查看脚本](./Clash-Verge-Rev-RouteKit-Premium-Primary-v4.js)。

先选精品机场订阅，再在本机填写脚本顶部的经济机场 Clash/Mihomo 订阅链接。不要提交填写过链接的脚本。

规则来源：[blackmatrix7](https://github.com/blackmatrix7/ios_rule_script)、[MetaCubeX](https://github.com/MetaCubeX/meta-rules-dat)；脚本参考 [Mihomo-RouteKit](https://github.com/skullvek/Mihomo-RouteKit/tree/760a342e91568167ee608a6fb4a6b721b65f5a76)。`rules/` 保存了 RouteKit 三份自定义规则的备份；脚本目前仍引用上游，不会自动切换到备份。
